# 给他爱6 · GTA6

中文单人 3D 浏览器游戏。试玩包含三个开放街区、主线「夜班急件」、海堤计时赛、车库、武器训练、帮派事件，以及模拟登录、充值和签到的紫金大厅。

## 启动

```sh
npm ci
npm run dev
```

电脑打开终端显示的本地网址。手机或平板和电脑连接同一网络后，用浏览器打开终端显示的局域网网址并横屏。游戏需要支持 WebGL 2 的浏览器。试玩进度按浏览器和网址保存在本机。

```sh
npm run build
npm run preview
```

`dist/` 可以放到静态站点。游戏运行时从本项目加载模型、图像和声音。

## 发布到 GitHub Pages

将 `main` 推送到目标 GitHub 仓库，并在 **Settings → Pages → Build and deployment** 中将 **Source** 设为 **GitHub Actions**。首次启用后，可以在 **Actions → 发布潮线夜驶** 手动运行。之后推送到 `main` 会自动构建并发布。

发布完成后，从 **Settings → Pages** 打开试玩地址。项目站点的默认路径是 `https://<账号>.github.io/<仓库名>/`，构建使用相对路径。试玩存档按网站地址保存在浏览器中，首次打开 GitHub Pages 站点会从新存档开始。

## 操作

| 操作 | 电脑 | 手机和平板 |
| --- | --- | --- |
| 移动与驾驶 | WASD，Shift 冲刺，空格手刹 | 左侧摇杆，右侧按键加速、刹车及手刹 |
| 镜头、瞄准和攻击 | 拖动视角，右键瞄准，左键或 Enter 出拳或开火 | 右侧拖动，并点按瞄准及攻击按钮 |
| 交互、抢车和上下车 | E | 点击画面中的交互提示 |
| 武器 | Q 切换，R 装填 | 右侧按钮 |
| 地图、暂停、脱困 | M、Esc、长按 T | 右上角地图和暂停，暂停菜单中可脱困 |

模拟礼包实付 0 元。试玩身份只用昵称和本机编号，签到按设备日期累计。

大厅可从「载具」选车并出发，从「武器」或「装备」直达训练场，从「街区」前往帮派事件。手机横屏时可在底栏打开「武器」，并从「更多」进入街区地图。手机或平板竖屏时会暂停游玩。横屏宽度不足 560 CSS 像素时也会显示提示。

从「街区 → 街头追逐」可以直接体验抢车和警方通缉。星级从一到五，星级越高，警力越多。五颗星会出现空中探照灯。脱离游戏内巡逻视野进入搜索，倒计时结束后恢复自由巡游。

驾驶时按 W 加速，按 S 先制动，停车后继续按住才会倒车。手机的油门和刹车按钮对应同样操作。高速转弯时转向幅度会减小，手刹可以甩尾。车辆彼此撞击会发生位移并损失车况，车速过高时乘员可能受伤。车辆也会撞到行人。

任务和比赛发放潮票。玩家可在武器商店购买武器和补充弹药，也可以使用签到补给券。角色死亡后会失去钱包里的全部潮票并送到医院，出院时恢复生命值。已购装备会保留，进行中的任务或比赛会结束。

## 美术与音乐

大厅封面渲染自本作城市场景。车库、港区和街道使用了 Kenney 的 CC0 模型。游戏音乐使用 Alex McCulloch 的 CC0 曲目《Synth Wave》剪辑版。授权及文件说明见 [素材清单](ASSETS.md)。
